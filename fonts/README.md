# Fonts

Free recreations of the fonts used in the D&D 5e books, by Solbera, with fixes by Ryrok and Ners
(<https://github.com/jonathonf/solbera-dnd-fonts>). Licensed CC BY-SA 4.0 (see `LICENSE.txt`).
The woff2 conversions come from the Homebrewery (<https://github.com/naturalcrit/homebrewery>).

| File | Imitates | Used for |
|---|---|---|
| bookinsanity*.woff2 | Bookmania | body text |
| mr-eaves-small-caps.woff2 | Mrs Eaves Small Caps | headings |
| nodesto-caps-condensed.woff2 | Modesto Condensed | app title |
| scaly-sans*.woff2 | Scala Sans | tables, buttons, small UI text |
