# D&D 5e Structured Data Sources

| Website | Contains |
|---|---|
| [Open5e](https://open5e.com) | REST API (JSON): SRD + OGL third-party content (Kobold Press etc.) — spells, classes, monsters, items, feats |
| [D&D 5e SRD API](https://www.dnd5eapi.co) | REST/GraphQL API (JSON): official SRD only |
| [5e-bits/5e-database](https://github.com/5e-bits/5e-database) | Raw SRD JSON files behind dnd5eapi.co |
| [SRD 5.1 / 5.2](https://www.dndbeyond.com/srd) | Official CC-BY-4.0 rules reference (PDF; community Markdown/JSON conversions on GitHub) |
| [Foundry VTT dnd5e](https://github.com/foundryvtt/dnd5e) | SRD compendium packs as detailed JSON source files |
| Fight Club 5e / Game Master 5e compendiums (GitHub) | Community XML compendiums covering many sourcebooks |
| [Roll20 Compendium](https://roll20.net/compendium/dnd5e) | Structured compendium; export limited to purchased content |
| [5e.tools](https://5e.tools) | Comprehensive JSON for official + expansion books (non-SRD content, legally gray) |
| [D&D Beyond](https://www.dndbeyond.com) | All official books you own; no public API/export |
| [5e.tools homebrew repo](https://github.com/TheGiddyLimit/homebrew) | Third-party and homebrew content in 5e.tools JSON schema |
| [The Homebrewery](https://homebrewery.naturalcrit.com) / [GM Binder](https://www.gmbinder.com) | Homebrew content in Markdown |
